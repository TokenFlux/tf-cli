# @tokenflux/tf platform binary

This is an internal platform package carrying the precompiled `tf` binary for a specific operating system and architecture.

Do not install or depend on this package directly. Install the main CLI package instead:

```sh
npm install -g @tokenflux/tf
```

Or run via npx:

```sh
npx @tokenflux/tf
```

Source code and documentation are available at [TokenFlux/tf-cli](https://github.com/TokenFlux/tf-cli).
